# MAFIA VMEDA

Бесплатный Telegram-бот для игры в «Мафию» в группах ВМедА. Проект рассчитан
на партии от 4 до 50 человек и использует собственные названия ролей, тексты и
оформление.

## Что уже реализовано

- чистая модульная архитектура на `aiogram 3`;
- игровая модель и конечный автомат фаз;
- распределение 13 ролей для партий до 50 игроков;
- полный цикл «ночь → обсуждение → голосование → вердикт» с таймерами;
- личные кнопки целей для всех активных ночных ролей;
- дневное голосование, ничья без казни и воздержание;
- наследование ролей Главы мафии и Комиссара;
- одно самолечение Дохтора и дневной блок Белоснежки;
- случайный подопечный Адвоката и передача проверок Прапорщику;
- посмертный выбор цели Лучшим другом;
- проверка победы мирных, мафии, Маньяка и Самоубийцы;
- групповое лобби с присоединением, выходом и запуском;
- подтверждение готовности игроков и управление лобби создателем/администратором;
- страницы по 8 целей для партий до 50 человек;
- идентификатор партии и фазы во всех игровых кнопках;
- единый игровой пост, который удаляется и публикуется заново при смене фазы;
- кнопки статуса, списка игроков, личного меню и досрочного завершения обсуждения;
- блокировка чата для посторонних на время партии;
- автоматическое ограничение сообщений ночью, после смерти и дневного блока;
- восстановление исходных прав группы и личных ограничений после партии;
- личное меню `/menu` с ролью, фазой, таймером и доступом к ночным действиям;
- закрытая админ-панель `/admin` со списком пользователей, карточками и общей статистикой;
- постоянное игровое имя `/name`, используемое в списках, действиях и голосованиях;
- личные команды `/start`, `/menu`, `/roles`, `/rules`;
- постоянные снимки активной партии в PostgreSQL/SQLite после каждого действия;
- восстановление фазы и таймера после перезапуска процесса;
- профили, рейтинг группы и сохранение сообщений об ошибках;
- модели SQLAlchemy для пользователей, чатов, партий, участников и статистики;
- конфигурация баланса и таймингов в YAML;
- unit-тесты ключевой игровой логики.

## Быстрый запуск

```bash
python3.12 -m venv .venv
source .venv/bin/activate
pip install -e '.[dev]'
cp .env.example .env
```

Создайте бота через `@BotFather`, запишите токен в `.env`, затем запустите:

```bash
python -m app.main
```

Для локальной разработки используется SQLite. Для production укажите
`DATABASE_URL=postgresql+asyncpg://...`. Redis включён в Docker Compose как
основа для нескольких процессов и распределённых блокировок; при запуске одного
экземпляра бота активные партии и сроки фаз надёжно хранятся в SQL-базе.

## Запуск на Railway

Проект готов к сборке через корневой `Dockerfile`. После подключения GitHub-
репозитория добавьте в Railway → сервис бота → Variables:

```env
BOT_TOKEN=токен_из_BotFather
```

Для короткого тестового запуска SQLite будет создан в `/data`. Для постоянного
хранения обязательно добавьте Railway PostgreSQL и передайте боту его
`DATABASE_URL` — обычный адрес Railway вида `postgresql://...` преобразуется в
асинхронный формат автоматически. На Railway запустите один экземпляр сервиса.

Не добавляйте токен в GitHub и не записывайте его в `.env.example`.

Готовый квадратный аватар находится в `assets/mafia-vmeda-avatar.png`. Его можно
загрузить через BotFather командой `/setuserpic`. Это оригинальный неофициальный
знак проекта без использования официального герба или эмблемы академии.

## Права бота в группе

Для полноценной игры бот должен быть администратором с правами:

- удалять сообщения;
- ограничивать участников;
- закреплять сообщения.

Перед запуском партии бот проверяет эти права. Без права ограничивать участников
или удалять сообщения партия не начнётся, чтобы чат не остался в некорректном
состоянии.

## Настройка таймеров

Длительность фаз можно изменить в `.env`:

```env
NIGHT_SECONDS=60
DISCUSSION_SECONDS=120
VOTING_SECONDS=60
VERDICT_SECONDS=30
```

## Команды MVP

- `/start` — создать или открыть игровое меню в группе;
- `/game` — создать игровое лобби;
- `/menu` — поднять текущий игровой пост с кнопками;
- `/name Ваше имя` — сохранить понятное имя игрока;
- `/players` — показать участников;
- `/status` — показать фазу и оставшееся время;
- `/startgame` — запустить партию;
- `/leave` — выйти из лобби;
- `/stopgame` — остановить партию создателем или администратором;
- `/profile` — личная статистика в этой группе;
- `/top` — рейтинг игроков группы;
- `/report текст` — сохранить сообщение об ошибке;
- `/roles` — описание ролей;
- `/rules` — правила игры.

Команда `/admin` отображается и работает только в личном чате владельца, чей
Telegram ID задан в `BOT_ADMIN_ID` (по умолчанию `1326779223`).

## Изменение названий и баланса

Названия и описания ролей находятся в `app/config/role_texts.yaml`. Порог появления
ролей и количество мафии для каждого диапазона игроков находятся в
`app/config/role_balance.yaml`. Их можно менять без правки игрового движка.

## Ограничение развёртывания

Текущая Railway-конфигурация использует long polling и рассчитана на один
экземпляр сервиса. Состояние партии переживает перезапуск, но горизонтальное
масштабирование на несколько одновременно работающих экземпляров требует
распределённой блокировки через Redis.
